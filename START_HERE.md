## 🚀 5 Bước Tiếp Theo (Tổng: 45 phút)

### Step 1: GitHub Setup (5 phút)
```
✓ Tạo GitHub Account
✓ Tạo Repository (devops-cicd-demo)
✓ Chọn: Public
```

### Step 2: Push Code (10 phút)
```bash
git init
git add .
git branch -M main
git remote add origin https://github.com/[USERNAME]/devops-cicd-demo.git
git commit -m "Initial commit"
git push -u origin main
```

### Step 3: Verify CI (5 phút)
```
✓ GitHub → Actions tab
✓ Xem "CI Check" workflow
✓ Status: 🟢 PASS
```

### Step 4: Deploy to Vercel (10 phút)
```
✓ Vercel.com → Sign up with GitHub
✓ Add Project → Import Repository
✓ Click Deploy
✓ Chờ 1-2 phút
```

### Step 5: Test Auto-Deploy (10 phút)
```
✓ Sửa file index.html
✓ Push code
✓ Xem CI run
✓ Xem Vercel deploy
✓ Website update (~30s)
```
